# Scalability and Cross-platform

- Pertahankan business logic terpisah dari UI bila cocok dengan arsitektur.
- Hindari asumsi ukuran layar, input device, filesystem, path, permission, dan lifecycle platform.
- Perhatikan responsive UI, accessibility, localization, keyboard/mouse/touch, memory, network, dan performance.
- Gunakan platform abstraction hanya ketika ada kebutuhan nyata.
- Hindari premature optimization dan arsitektur untuk kebutuhan hipotetis.
- Untuk Flutter, pastikan keputusan layout dan state mendukung web serta mobile tanpa melanggar pola existing.
