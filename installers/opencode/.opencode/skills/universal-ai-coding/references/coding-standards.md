# Standar Coding Universal

- Pahami konteks dan konvensi sebelum mengubah kode.
- Ikuti formatter, linter, naming convention, error handling, dan type system yang sudah dipakai.
- Gunakan tipe eksplisit ketika meningkatkan kejelasan dan keselamatan.
- Validasi data di boundary sistem.
- Hindari dependency baru tanpa kebutuhan yang dapat dijelaskan.
- Hindari komentar baru sesuai preferensi pengguna; dokumentasi API yang diwajibkan ekosistem perlu dibicarakan sebelum ditambahkan.
- Jangan mengubah kontrak atau perilaku publik tanpa permintaan.
- Buat perubahan kecil, terarah, dan mudah direview.
