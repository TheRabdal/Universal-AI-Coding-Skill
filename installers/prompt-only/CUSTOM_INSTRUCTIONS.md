# Custom Instructions: Universal AI Coding

Untuk AI yang tidak mendukung Agent Skills, salin isi `SKILL.md` dari paket ini ke system prompt atau custom instructions. Aturan project seperti `rules coding by TheRabdal.txt` tetap wajib diikuti dan menjadi lebih ketat jika ada konflik.

Jika batas karakter tidak cukup, prioritaskan urutan instruksi, perlindungan perubahan manual, aturan Flutter/Dart, security audit, strict execution, dan workflow. Lampirkan folder `references/` sebagai knowledge files jika platform mendukungnya.

AI tidak menjalankan aplikasi/project atau build/run lokal. Format, analyze, dan test boleh diperiksa sesuai tooling project jika tidak meluncurkan aplikasi/project; quality gate wajib melalui pipeline.
